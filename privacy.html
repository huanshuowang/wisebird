隐私政策

Wisebird 择木 Chrome 扩展 · 最后更新：2026 年 10 月 4 日

一句话版本

Wisebird 没有账号体系，也没有接收你数据的自有服务器。简历、设置和 API Key 保存在你自己的浏览器里。只有你点「分析」时，插件才用你自己的 Key，把岗位内容和简历直接发给你选的 AI 服务商。不出售任何数据，插件里也没有统计或追踪代码。

保存了什么、存在哪里

以下内容只保存在你电脑上 Chrome 的扩展本地存储（chrome.storage.local）里，不会同步到任何 Wisebird 服务器；卸载插件时 Chrome 会一并删除。

  • 你粘贴的简历，以及你填写的身份和偏好（例如是否需要办身份、入职时间、经验宽限、预期年薪）。
  • 你选择的 AI 服务商和 API Key。
  • 分析结果：已分析岗位的缓存（再次打开时不重复调用 AI）、存档和收藏，以及批量分析的进度。

什么时候发送数据、发给谁

只有在你点击分析、初筛或批量分析时才会发送。插件会用你的 API Key，从你的浏览器直接把以下内容发给你在设置里选的 AI 服务商（Google Gemini、DeepSeek、OpenAI 或 Anthropic）：

  • 岗位页面的文字（初筛时是搜索结果页上的岗位卡片），包括页面标题和岗位链接；
  • 你的简历，以及上面列出的身份和偏好设置。

服务商会按照它自己的隐私政策和条款处理这些请求。各家规则不同：部分免费额度可能会用你的输入改进产品（例如 Gemini API 的免费额度），数据存放的国家也不同（DeepSeek 的服务器在中国）。介意的话，请据此选择服务商，或使用付费 Key。

Wisebird 不做的事

  • 没有接收你简历、岗位内容或 API Key 的服务器，也没有账号体系。
  • 插件里没有统计、追踪或广告代码。
  • 不出售、不转让你的数据，也不把数据用于广告、信用评估或任何与「帮你分析岗位」无关的用途。
  • 不会替你投递简历，也不会代你提交任何内容。

每项权限的用途

  • activeTab、scripting：你点图标时，读取当前页面上的岗位描述。
  • tabs：批量分析时，找出当前窗口里打开的岗位标签页并读取内容；从存档里打开保存过的岗位。标签页地址只在你的电脑上判断，只有正在分析的那个岗位链接会随分析请求一起发送。
  • storage：把设置、简历和分析结果保存在你的浏览器里。
  • 访问 AI 服务商域名（Gemini、DeepSeek、OpenAI、Anthropic）：把分析请求发给你选的服务商。
  • 访问招聘网站（LinkedIn、Handshake，以及 Greenhouse、Lever、Workday 等常见招聘系统）：批量分析时读取这些标签页里的岗位描述，包括嵌在公司招聘页里的内容。
  • 可选的其他网站访问权限：只有你主动开启时才会申请，用于批量分析其他公司招聘页上的岗位。

网站、欢迎页和反馈问卷

安装插件后会打开本网站上的欢迎页，卸载时会打开一个简短的反馈页；卸载页的地址里只带插件版本号和语言。本网站是托管在 GitHub Pages 上的静态网站，没有统计代码；GitHub 可能按其政策保留常规的服务器日志。卸载反馈和内测申请使用 Google Forms，是否填写由你决定，回答由 Google 按其政策处理。

有限使用声明

Wisebird 对用户数据的使用遵守 Chrome 应用商店用户数据政策（Chrome Web Store User Data Policy），包括其中的有限使用（Limited Use）要求。

政策变更

本政策如有变化，会更新页首日期。如果将来加入经 Wisebird 中转服务调用 AI 的内置额度，会在该模式上线前更新本页并在插件内说明；自带 Key 的模式仍按本页所述方式工作。
