三步，大约三分钟。

设置好以后，打开任何岗位，点一下就知道值不值得投，以及为什么。

  1. 固定到工具栏

    点 Chrome 右上角的拼图图标 🧩，找到 Wisebird，点旁边的图钉。之后绿色放大镜就一直在工具栏上。

  2. 设置：选 AI，粘贴 Key 和简历

    点 Wisebird 图标，再点右上角的设置图标。选一个 AI 服务商，粘贴它的 API Key；需要办身份就保持勾选。入职时间、经验宽限、预期年薪都可以不填。最后粘贴简历，改动会自动保存。

    Gemini Key · 有免费额度 ↗ DeepSeek ↗ OpenAI ↗ Claude ↗

  3. 打开一个岗位，点图标

    LinkedIn、Handshake，或任何带岗位描述的页面都可以。点图标，再点「分析」。开了一堆岗位？用「批量」一次看完。
